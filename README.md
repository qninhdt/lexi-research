# lexi-research

Distil a frontier sentence grader into a small local student model.

The student reads a learner-written English sentence plus **one specific
dictionary sense** of a target word, and returns an inline correction, a meaning
band, and one line of feedback. Grammar and naturalness bands are *computed from
the correction's error tags*, not generated by the model.

Plan: [`plans/260729-1555-sentence-grader-distillation-pipeline/plan.md`](plans/260729-1555-sentence-grader-distillation-pipeline/plan.md)
Design: [`docs/grader-distillation-design.md`](docs/grader-distillation-design.md)

## Output contract

```json
{ "correction": "He [speak>speaks:agr] very [eloquent>eloquently:form].",
  "meaning": 3,
  "feedback": "Right sense, but the verb needs to agree with the subject." }
```

| Operation | Syntax | Example |
|---|---|---|
| Replace | `[A>B:tag]` | `[speak>speaks:agr]` |
| Delete | `[A>:tag]` | `the [the>:art] very` |
| Insert | `[>B:tag]` | `went [>to the:art] store` |

A clean sentence is re-emitted verbatim, so it costs zero extra tokens. An
unreadable sentence yields `correction: null`, which floors `grammar` at 0 rather
than letting "no parseable edits" score as a perfect 4.

## Development

```bash
uv sync
uv run pytest
uv run mypy lexi_research/
uv run ruff check .
```

Requires Python >= 3.10.

## Running the pipeline

Copy `.env.example` to `.env` and set the local source database plus an
OpenAI-compatible teacher endpoint. Then run the safe one-call credential and
format check before generating data:

```bash
uv run python -m lexi_research.teacher.probe
```

The source export is reproducible without teacher credentials:

```bash
LEXI_SOURCE_DB=/absolute/path/to/lexi-ai/data uv run dvc repro export
```

Teacher generation, calibration, training, and deployment remain gated on the
pilot measurements described in the plan; no adapter is currently released.

## Status

Phase 1 (format core) only. Bands are **uncalibrated** — `band_config.json` has
`"calibrated": false`, and the eval harness must refuse to report band metrics
until Phase 6 flips it.
